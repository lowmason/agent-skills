# sources/

The files in this folder are verbatim copies of U.S. Government works. The U.S. Census Bureau publishes the county Gazetteer file. The `*list1*` files are the Office of Management and Budget (OMB) delineation files, hosted by the Census Bureau.

These files are in the public domain under 17 U.S.C. § 105.

The skill's MIT `LICENSE` covers this repo's own code and text. It does not cover these files.

[`../MANIFEST.md`](../MANIFEST.md) records each file's source URL, sha256 and retrieval time.
