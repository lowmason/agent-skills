### R3. Operations
S129. R3.1. `build/versions.py` has these subcommands:
S130. | Subcommand | Network | Effect |
S131. | `sync [--check]` | no | Writes or checks the R2.1 outputs |
S132. | `run <gate> [--pin pkg==X ...] -- <cmd>` | yes | Runs `<cmd>` under `uv run` with the gate's stack and the freeze date |
S133. | `verify [--pin pkg==X ...]` | yes | Runs the re-verify set on the file's versions: Tier 2, Tier 3, the JAX CPU examples, and `run_suites.py --all --extras` |
S134. | `bump [--date D] [--only pkg ...]` | yes | Sets the freeze date (default: today) and does one joint resolve, as of that date and on the dev Python, of every `[packages]` entry together. It rewrites `[packages]` from the result and runs `sync`. With `--only`, the other entries stay at their pins in the joint resolve |
S135. | `drift [--pin pkg==X ...]` | yes | Does the same joint resolve as `bump`, with no freeze date and no pins, in two passes: first on the dev Python, then on the newest stable Python. For each pass it reports, for each `[packages]` and `[cited]` entry, the pinned version, the resolved version, the newest release and its upload date. It flags each package that resolves below its newest release. It then runs the re-verify set on each pass's versions and reports each gate's result for each pass |
S136. | `check` | no | The R4 lint |
S137. R3.2. `bump` never changes `[cited]`.
S138. A person changes a `[cited]` entry only after re-checking the cited behavior.
S139. R3.3. `--pin` changes one package for one run and never edits the file.
S140. R3.4. A bump follows these steps, in one change:
S141. 1. Run `bump`.
S142. 2. Run `verify`.
S143. 3. Run `check`, which lists each prose citation that the bump made stale.
S144. 4. Re-verify or rewrite each stale citation (R5.5).
S145. 5. Commit.
S146. R3.5. Exit codes:
S147. - `run` and `verify` exit non-zero on any failure.
S148. - `drift` exits 0 when each gate passes on the latest versions, 1 when a gate fails, and 2 when it cannot resolve or reach the network.
S149. The report states which.
S150. - `bump` exits 2 on a network or resolve failure and names the step.
S151. R3.6. Errors name their cause:
S152. - A missing or invalid file names the key.
S153. - An unknown package in `[gates]` or `[[override]]` names the package.
S154. - An invalid date names the value.
S155. - A pin uploaded after the freeze date names the package and the date.
S156. - A joint resolve that fails in `bump` or `drift` names the packages in conflict.
S157. This is how a conflict under D2 (one version per package) becomes visible.

### R4. The `check` lint
S158. R4.1. `versions.py check` runs offline.
S159. It fails on any of these:
S160. 1. **Sync.** An R2.1 output differs from the file.
S161. 2. **Interpreter literals.** A live file spells `--python 3.<n>`.
S162. Live files are `CLAUDE.md`, `AGENTS.md`, `GEMINI.md` and the files under `build/`, `hooks/`, `skills/` and `.claude/skills/`.
S163. An interpreter path such as `/usr/bin/python3` is not a literal.
S164. 3. **Prose citations.** In `skills/**/*.md` and the script headers under `skills/*/scripts/`, `check` finds each version that stands next to a `[packages]` name, a `[cited]` name or "Python", and classifies it by form:
S165. - **Equality** ("verified on Polars 1.42", `numpyro==0.22.0`, "checked in the 0.22.0") must equal the file's value at the cited precision.
S166. - **Range** (`>=`, `≥`, `<`, `,<0.18`, "3.11+") must contain the file's value.
S167. - **History** ("ArviZ 0.23", "and earlier") passes only through the `HISTORICAL` allowlist.
S168. 4. **Floors.** Each script's `requires-python` must match the Python floor in its `SKILL.md` `compatibility:` line.
S169. The dev Python must satisfy each floor.
S170. R4.2. `HISTORICAL` is keyed by the literal phrase, not by file and line, and each entry gives its reason.
S171. It follows the model of `DOCUMENTED_ABSENT` in `build/check_snippets.py`.
S172. R4.3. `check` does not read `specs/`, `LICENSE*` files, `data/` directories or test fixtures.

714| '''One source for every pinned or cited package version, the dev interpreter and the freeze date.
715| 
716| build/versions.toml is the only file where a person sets one of them. This script reads it:
717| 
718|     uv run python build/versions.py sync [--check]
719|     uv run python build/versions.py run GATE [--pin PKG==X ...] -- COMMAND ...
720|     uv run python build/versions.py verify [--pin PKG==X ...]
721|     uv run python build/versions.py bump [--date YYYY-MM-DD] [--only PKG ...]
722|     uv run python build/versions.py drift [--pin PKG==X ...]
723|     uv run python build/versions.py check
724| 
725| sync writes .python-version, uv.toml and skills/uv.toml, and --check fails when one differs.
726| run installs a gate's pinned stack and runs COMMAND under uv with the freeze date. verify runs the
727| re-verify set. bump moves the freeze date and re-pins [packages] by one joint resolve. drift does the
728| same resolve with no freeze date and reports it. check is the offline commit lint.
729| --python and --no-freeze on run and verify exist for drift's second pass.
730| 
731| Exit status: 0 on success; 1 when a check, a gate or a sync comparison fails; 2 for a usage error, an
732| invalid versions file or a network or resolve failure (the message names the cause).
733| Design: specs/package-versions.md.
734| '''
735| import argparse
736| import datetime
737| import re
738| import sys

740| from collections.abc import Mapping, Sequence
741| from dataclasses import dataclass

762| class VersionsError(Exception):
763|     '''An invalid or unreadable versions file; the message names the cause.'''

766| def normalize(name: str) -> str:
767|     '''PEP 503 form, which is how uv prints a package name.'''
768|     return re.sub(r'[-_.]+', '-', name).lower()
769| 
770| 
771| def version_tuple(text: str) -> tuple[int, ...]:
772|     return tuple(int(part) for part in text.split('.'))
773|

775| def compare(a: str, b: str) -> int:
776|     '''-1, 0 or 1; the shorter version is padded with zeros.'''
777|     x, y = version_tuple(a), version_tuple(b)
778|     width = max(len(x), len(y))
779|     x, y = x + (0,) * (width - len(x)), y + (0,) * (width - len(y))
780|     return (x > y) - (x < y)

783| @dataclass(frozen=True)
784| class Override:
785|     gate: str
786|     package: str
787|     version: str
788|     reason: str

791| @dataclass(frozen=True)
792| class Versions:
793|     dev_python: str
794|     freeze: datetime.date
795|     packages: dict[str, str]
796|     cited: dict[str, str]
797|     gates: dict[str, tuple[str, ...]]
798|     overrides: tuple[Override, ...] = ()
799| 
800|     @property
801|     def cutoff(self) -> str:
802|         '''00:00:00Z on the day after the freeze date, so the freeze day itself is included.'''
803|         return f'{self.freeze + datetime.timedelta(days=1):%Y-%m-%d}T00:00:00Z'
804| 
805|     def stack(self, gate: str, pins: Mapping[str, str] | None = None) -> list[str]:
806|         '''The `pkg==version` strings of a gate: [packages], then overrides, then --pin values.'''
807|         if gate not in self.gates:
808|             raise VersionsError(f'unknown gate {gate!r}; the gates are {", ".join(self.gates)}')
809|         pins = {normalize(k): v for k, v in (pins or {}).items()}
810|         out = []
811|         for package in self.gates[gate]:
812|             version = self.packages[package]
813|             for override in self.overrides:
814|                 if override.gate == gate and override.package == package:
815|                     version = override.version
816|             out.append(f'{package}=={pins.get(normalize(package), version)}')
817|         return out
818| 
819|     def pins(self) -> dict[str, str]:
820|         '''Every [packages] entry, keyed by normalised name; what a suite run installs.'''
821|         return {normalize(name): version for name, version in self.packages.items()}

824| def _table(data: dict, key: str, where: str) -> dict:
825|     value = data.get(key)
826|     if not isinstance(value, dict):
827|         raise VersionsError(f'{where}: missing table [{key}]')

831| def parse(text: str, where: str = VERSIONS_FILE) -> Versions:
832|     '''Validate the file's text; every error names its key, package, date or value.'''
833|     try:
834|         data = tomllib.loads(text)
835|     except tomllib.TOMLDecodeError as exc:
836|         raise VersionsError(f'{where}: invalid TOML: {exc}') from exc
837|     known = {'python', 'freeze', 'packages', 'cited', 'gates', 'override'}
838|     for key in data:
839|         if key not in known:
840|             raise VersionsError(f'{where}: unknown table {key!r}')
841|     dev = _table(data, 'python', where).get('dev')
842|     if not isinstance(dev, str) or not PYTHON_RE.fullmatch(dev):
843|         raise VersionsError(f"{where}: [python] dev must be a string such as '3.13', got {dev!r}")
844|     date = _table(data, 'freeze', where).get('date')
845|     if not isinstance(date, datetime.date) or isinstance(date, datetime.datetime):
846|         raise VersionsError(f'{where}: [freeze] date must be a TOML date such as 2026-10-19, got {date!r}')
847|     packages = dict(_table(data, 'packages', where))
848|     cited = dict(data.get('cited', {}))
849|     for table, entries in (('packages', packages), ('cited', cited)):
850|         for name, version in entries.items():
851|             if not isinstance(version, str) or not VERSION_RE.fullmatch(version):
852|                 raise VersionsError(f'{where}: [{table}] {name}: invalid version {version!r}')
853|     for name in packages:
854|         if normalize(name) in {normalize(c) for c in cited}:
855|             raise VersionsError(f'{where}: {name} is in both [packages] and [cited]')
856|     gates = {}
857|     for gate, members in _table(data, 'gates', where).items():
858|         if not isinstance(members, list) or not members or not all(isinstance(m, str) for m in members):
859|             raise VersionsError(f'{where}: [gates] {gate} must be a non-empty list of package names')
860|         for member in members:
861|             if member not in packages:
862|                 raise VersionsError(f'{where}: [gates] {gate} names {member}, which has no [packages] entry')
863|         gates[gate] = tuple(members)
864|     overrides = []
865|     for i, table in enumerate(data.get('override', []), start=1):
866|         for key in OVERRIDE_KEYS:
867|             if not isinstance(table.get(key), str) or not table[key]:
868|                 raise VersionsError(f'{where}: [[override]] {i}: missing key {key!r}')
869|         if table['gate'] not in gates:
870|             raise VersionsError(f"{where}: [[override]] {i}: unknown gate {table['gate']!r}")
871|         if table['package'] not in gates[table['gate']]:
872|             raise VersionsError(f"{where}: [[override]] {i}: {table['package']} is not in gate {table['gate']}")
873|         if not VERSION_RE.fullmatch(table['version']):
874|             raise VersionsError(f"{where}: [[override]] {i}: invalid version {table['version']!r}")
875|         overrides.append(Override(*(table[key] for key in OVERRIDE_KEYS)))
876|     return Versions(dev, date, packages, cited, gates, tuple(overrides))

879| def load(root: Path = REPO) -> Versions:
880|     path = root / VERSIONS_FILE
881|     try:
882|         text = path.read_text(encoding='utf-8')
883|     except (OSError, UnicodeDecodeError) as exc:
884|         raise VersionsError(f'{VERSIONS_FILE}: cannot read: {exc}') from exc
885|     return parse(text)

888| def rewrite(text: str, date: datetime.date | None = None, packages: Mapping[str, str] | None = None) -> str:
889|     '''The file's text with the freeze date and [packages] values replaced; comments and order stay.'''
890|     out, table = [], ''
891|     for line in text.splitlines(keepends=True):
892|         header = re.match(r'\s*\[+([^\]]+)\]+', line)
893|         if header:
894|             table = header.group(1)
895|         elif date and table == 'freeze' and re.match(r'\s*date\s*=', line):
896|             line = re.sub(r'=\s*\S+', f'= {date.isoformat()}', line, count=1)
897|         elif packages and table == 'packages':
898|             match = re.match(r"(\s*)([\w.-]+)(\s*=\s*)'[^']*'(.*)$", line, re.S)
899|             if match and match.group(2) in packages:
900|                 line = f"{match.group(1)}{match.group(2)}{match.group(3)}'{packages[match.group(2)]}'{match.group(4)}"
901|         out.append(line)
902|     return ''.join(out)

911|                     f'exclude-newer = "{v.cutoff}"\n'),
912|         'skills/uv.toml': (f'{SYNC_NOTE}# No settings. This file stops uv from reading the repo-root uv.toml for scripts under\n'
913|                            '# skills/, so a skill script that a user runs floats within its own dependency floors.\n'
914|                            '# The repo\'s checks pass --exclude-newer themselves (build/versions.py run, build/run_suites.py).\n'),
915|     }

926|             continue
927|         if check:
928|             problems.append(f'{rel}: {"missing" if current is None else "differs"}; run build/versions.py sync')
929|         else:
930|             path.write_text(text, encoding='utf-8')
931|     return problems
