Your small timer may be measuring asynchronous submission: JAX can return an array before its computation finishes. A later host read then pays the remaining wait. For a completed device call, make the inputs and parameters ready before starting, and call `jax.block_until_ready(output)` on the entire returned PyTree before stopping. For request latency, start before preprocessing and stop after fetching and consuming the outputs. These answer different questions. [JAX asynchronous dispatch](https://docs.jax.dev/en/latest/async_dispatch.html), [full-tree completion](https://docs.jax.dev/en/latest/_autosummary/jax.block_until_ready.html).

The input-length effect has at least two plausible causes: a new shape can require a new specialization, and longer inputs can require more computation or transfer. Replay A,A,B,B,A with one stable callable. A first visit that is slow with target compilation logs, followed by fast repeats and a fast revisited A, supports specialization overhead. Longer warm calls without new compilation messages support length-dependent execution costs. Your description alone does not establish which dominates. Avoid creating `jit` wrappers around fresh lambdas inside the request loop, and inspect shapes, dtypes, weak types, static values, state structure, and placement together. Changing the numerical value of an ordinary dynamic scalar with the same abstract type does not normally require a new executable; making it static changes that contract. [JAX specialization and caching](https://docs.jax.dev/en/latest/jit-compilation.html).

Below is a complete standalone diagnostic fixture. It uses a deterministic float32 projection with both token and pooled outputs so that the completion barrier covers more than one output. This is a reproduction of the timing and specialization mechanisms; it does not claim to reproduce your actual model's bottleneck. The fixture disables the persistent compilation cache before backend initialization. In-process reuse remains enabled. Use a fresh process for first-encounter measurements; initialization and model/input construction are excluded. ```python
import argparse
import json
import platform
import sys
from time import perf_counter

import jax
import jax.numpy as jnp
import jaxlib
import numpy as np


WIDTH = 256
OUTPUT_WIDTH = 128
RTOL = 2e-4
ATOL = 2e-5

# These are the controlled fixture's policies, not changes to your model.
jax.config.update("jax_enable_compilation_cache", False)
jax.config.update("jax_default_matmul_precision", "highest")


def forward(params, inputs):
    token = jnp.tanh(inputs @ params["weight"] + params["bias"])
    return {
        "token": token,
        "pooled": jnp.mean(token, axis=0, dtype=jnp.float32),
    }


FORWARD = jax.jit(forward)  # Keep this callable alive across requests.


def reference(host_params, inputs):
    inputs = np.asarray(inputs, dtype=np.float32)
    token = np.tanh(inputs @ host_params["weight"] + host_params["bias"])
    return {
        "token": token,
        "pooled": np.mean(token, axis=0, dtype=np.float32),
    }


def assert_parity(host_params, inputs, output):
    expected = reference(host_params, inputs)
    actual = jax.device_get(output)
    assert set(actual) == set(expected)
    max_error = 0.0
    for name, target in expected.items():
        value = np.asarray(actual[name])
        assert value.shape == target.shape, (name, value.shape, target.shape)
        assert value.dtype == target.dtype == np.dtype("float32")
        assert np.isfinite(target).all() and np.isfinite(value).all()
        np.testing.assert_allclose(value, target, rtol=RTOL, atol=ATOL)
        error = np.abs(value.astype(np.float64) - target.astype(np.float64))
        max_error = max(max_error, float(np.max(error)))
    return max_error


def signature(tree):
    leaves, structure = jax.tree_util.tree_flatten_with_path(tree)
    return {
        "pytree": str(structure),
        "leaves": [
            {
                "path": str(path),
                "shape": list(value.shape),
                "dtype": str(value.dtype),
                "weak_type": bool(getattr(value, "weak_type", False)),
                "sharding": str(getattr(value, "sharding", None)),
            }
            for path, value in leaves
        ],
    }


def completed_call(function, params, inputs):
    jax.block_until_ready((params, inputs))
    start = perf_counter()
    output = function(params, inputs)
    submitted = perf_counter()
    jax.block_until_ready(output)
    completed = perf_counter()
    return output, {
        "submission_ms": 1000 * (submitted - start),
        "remaining_wait_ms": 1000 * (completed - submitted),
        "completed_call_ms": 1000 * (completed - start),
    }


def consume(host_output):
    # Host consumption is part of the fixture's request boundary.
    # The checksum is not its numerical correctness test.
    return sum(
        float(np.sum(value, dtype=np.float64))
        for value in jax.tree_util.tree_leaves(host_output)
    )


def natural_request(raw_input, params, device):
    start = perf_counter()
    host_input = np.asarray(raw_input, dtype=np.float32)
    inputs = jax.device_put(host_input, device)
    output = FORWARD(params, inputs)
    host_output = jax.device_get(output)
    checksum = consume(host_output)
    finish = perf_counter()
    return host_output, inputs, {
        "request_ms": 1000 * (finish - start),
        "checksum": checksum,
    }


def fenced_stages(raw_input, params, device):
    jax.block_until_ready(params)
    start = perf_counter()
    host_input = np.asarray(raw_input, dtype=np.float32)
    preprocessed = perf_counter()
    inputs = jax.device_put(host_input, device)
    jax.block_until_ready(inputs)
    placed = perf_counter()
    output = FORWARD(params, inputs)
    jax.block_until_ready(output)
    computed = perf_counter()
    host_output = jax.device_get(output)
    consume(host_output)
    fetched = perf_counter()
    return host_output, {
        "preprocess_ms": 1000 * (preprocessed - start),
        "placement_ms": 1000 * (placed - preprocessed),
        "completed_model_ms": 1000 * (computed - placed),
        "fetch_and_consume_ms": 1000 * (fetched - computed),
        "fenced_total_ms": 1000 * (fetched - start),
    }


def distribution(samples):
    values = np.asarray(samples, dtype=np.float64)
    return {
        "count": len(samples),
        "median_ms": float(np.median(values)),
        "p95_ms": float(np.percentile(values, 95)),
        "min_ms": float(np.min(values)),
        "max_ms": float(np.max(values)),
        "samples_ms": values.tolist(),
    }


def summarize(records):
    return {
        name: distribution([record[name] for record in records])
        for name in records[0]
        if name.endswith("_ms")
    }


def profile_request(raw_input, params, device):
    with jax.profiler.TraceAnnotation("request"):
        with jax.profiler.TraceAnnotation("preprocessing"):
            host_input = np.asarray(raw_input, dtype=np.float32)
        with jax.profiler.TraceAnnotation("placement_submission"):
            inputs = jax.device_put(host_input, device)
        with jax.profiler.TraceAnnotation("model_submission"):
            output = FORWARD(params, inputs)
        with jax.profiler.TraceAnnotation("host_fetch_and_consumption"):
            host_output = jax.device_get(output)
            consume(host_output)
            jax.block_until_ready(output)
    return host_output


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "mode", choices=["diagnose", "measure", "request", "aot", "profile"]
    )
    parser.add_argument("--lengths", default="128,128,512,512,128")
    parser.add_argument("--repeats", type=int, default=20)
    parser.add_argument("--aot-length", type=int, default=128)
    parser.add_argument("--trace-dir", default="/tmp/jax-inference-profile")
    args = parser.parse_args()
    lengths = [int(value) for value in args.lengths.split(",")]
    if min(lengths) < 1 or args.repeats < 1 or args.aot_length < 1:
        parser.error("lengths and repeats must be positive; empty prompts are undefined")

    diagnose = args.mode == "diagnose"
    jax.config.update("jax_log_compiles", diagnose)
    jax.config.update("jax_explain_cache_misses", diagnose)
    device = jax.local_devices()[0]
    rng = np.random.default_rng(20261003)
    host_params = {
        "weight": (0.01 * rng.normal(size=(WIDTH, OUTPUT_WIDTH))).astype(np.float32),
        "bias": np.linspace(-0.1, 0.1, OUTPUT_WIDTH, dtype=np.float32),
    }
    params = jax.device_put(host_params, device)
    jax.block_until_ready(params)
    unique_lengths = list(dict.fromkeys(lengths))
    all_lengths = list(dict.fromkeys(lengths + [args.aot_length]))
    host_inputs = {
        length: np.linspace(-1, 1, length * WIDTH, dtype=np.float32).reshape(
            length, WIDTH
        )
        for length in all_lengths
    }
    raw_inputs = {length: value.tolist() for length, value in host_inputs.items()}
    device_inputs = {
        length: jax.device_put(value, device) for length, value in host_inputs.items()
    }
    jax.block_until_ready(device_inputs)
    report = {
        "mode": args.mode,
        "python": platform.python_version(),
        "platform": platform.platform(),
        "jax": jax.__version__,
        "jaxlib": jaxlib.__version__,
        "numpy": np.__version__,
        "framework": "plain functional JAX; no model checkpoint",
        "backend": jax.default_backend(),
        "devices": [
            {"name": str(value), "kind": value.device_kind} for value in jax.devices()
        ],
        "selected_device": str(device),
        "process_index": jax.process_index(),
        "process_count": jax.process_count(),
        "local_device_count": jax.local_device_count(),
        "mesh": None,
        "x64_enabled": bool(jax.config.jax_enable_x64),
        "matmul_precision": str(jax.config.jax_default_matmul_precision),
        "storage_compute_accumulation_dtype": "float32",
        "persistent_compilation_cache": False,
        "parameter_signature": signature(params),
        "static_arguments": [],
        "callable_identity": id(FORWARD),
        "sequence": lengths,
        "batch": 1,
        "padding": "none",
        "randomness": "seeded parameter initialization; deterministic forward",
        "concurrency": "one serialized request at a time; no throughput claim",
        "boundaries": {
            "resident": "ready parameters/input to entire device output tree ready",
            "request": "existing host list to fetched and host-consumed output tree",
            "excluded": "imports, initialization, parameter placement, list construction",
        },
        "rtol": RTOL,
        "atol": ATOL,
    }
    max_error = 0.0

    if args.mode in {"diagnose", "measure", "request"}:
        visits = []
        seen_lengths = set()
        for index, length in enumerate(lengths):
            inputs = device_inputs[length]
            visit = {
                "visit": index,
                "length": length,
                "first_target_signature_encounter": length not in seen_lengths,
                "signature": signature((params, inputs)),
            }
            if diagnose:
                print("TARGET forward " + json.dumps(visit), file=sys.stderr, flush=True)
            if args.mode == "request":
                output, inputs, timing = natural_request(raw_inputs[length], params, device)
            else:
                output, timing = completed_call(FORWARD, params, inputs)
            visits.append({**visit, **timing})
            seen_lengths.add(length)
            max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
        report["visits_before_additional_warmup"] = visits
        report["output_signature"] = signature(output)

    if args.mode in {"measure", "request"}:
        warm_results = []
        for length in unique_lengths:
            inputs = device_inputs[length]
            completed_call(FORWARD, params, inputs)  # Exact-signature warm-up, excluded.
            request_records = []
            for _ in range(args.repeats):
                output, _, record = natural_request(raw_inputs[length], params, device)
                request_records.append(record)
            max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
            warm = {"length": length, "request": summarize(request_records)}
            if args.mode == "measure":
                resident_records = []
                stage_records = []
                for _ in range(args.repeats):
                    output, record = completed_call(FORWARD, params, inputs)
                    resident_records.append(record)
                max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
                for _ in range(args.repeats):
                    output, record = fenced_stages(raw_inputs[length], params, device)
                    stage_records.append(record)
                max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
                warm["resident"] = summarize(resident_records)
                warm["fenced_stages"] = summarize(stage_records)
            warm_results.append(warm)
        report["warm"] = warm_results

    if args.mode == "aot":
        length = args.aot_length
        inputs = device_inputs[length]
        aot = jax.jit(forward)  # This mode has made no target forward call.
        start = perf_counter()
        traced = aot.trace(params, inputs)
        traced_at = perf_counter()
        lowered = traced.lower()
        lowered_at = perf_counter()
        executable = lowered.compile()
        compiled_at = perf_counter()
        output, first_execution = completed_call(executable, params, inputs)
        max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
        records = []
        for _ in range(args.repeats):
            output, timing = completed_call(executable, params, inputs)
            records.append(timing)
        max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
        report["aot"] = {
            "length": length,
            "signature": signature((params, inputs)),
            "trace_ms": 1000 * (traced_at - start),
            "lower_ms": 1000 * (lowered_at - traced_at),
            "compile_or_reuse_ms": 1000 * (compiled_at - lowered_at),
            "first_execution": first_execution,
            "warm_execution": summarize(records),
        }

    if diagnose:
        # Run transfer diagnostics separately from comparison timings.
        length = lengths[-1]
        with jax.transfer_guard("log"):
            output, _, _ = natural_request(raw_inputs[length], params, device)
        max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
        report["diagnostic_timings_have_logging_overhead"] = True

    if args.mode == "profile":
        for length in unique_lengths:
            completed_call(FORWARD, params, device_inputs[length])
        with jax.profiler.trace(args.trace_dir):
            for _ in range(3):
                for length in lengths:
                    output = profile_request(raw_inputs[length], params, device)
        # Reference computation/assertions occur outside the captured workload.
        max_error = max(max_error, assert_parity(host_params, host_inputs[length], output))
        report["profile"] = {
            "directory": args.trace_dir,
            "requests": 3 * len(lengths),
            "status": "capture returned; inspect files and device events separately",
        }

    report["correctness"] = {
        "status": "all delivered assertions reached so far passed",
        "max_absolute_reference_error": max_error,
        "comparison": "independent NumPy token and pooled arrays; not a checksum",
        "scope": "deterministic projection; positive unpadded lengths only",
    }
    print(json.dumps(report, indent=2, sort_keys=True))


if __name__ == "__main__":
    main()

Read `compiles.log` around the `TARGET forward` markers and associate messages with the named target and the corresponding full input signature. Setup primitives can also log compilations. The expected pattern for this fixture is one target specialization for each distinct length, with reuse on repeats and the final revisited 128; the actual log is the evidence. Cache-miss messages and a Python trace event alone are insufficient to count backend executable compilations. Diagnostic timing includes logging overhead, so use the separate logging-disabled runs for latency comparisons. [JAX compilation logging and cache-miss controls](https://docs.jax.dev/en/latest/config_options.html).

The distributions in `measure` describe serialized, completed calls and warm requests. In `request`, the initial replay instead records the first target signature encounters within the host-to-host boundary. Preplaced inputs are available for signature recording, but each natural request places a newly constructed NumPy input. Parameters remain resident. Host-list construction and startup are deliberately outside this boundary; add tokenization, network queueing, scheduling, or checkpoint loading if your actual latency contract includes them. CPU placement and host fetch may share memory, so their times cannot predict accelerator transfer performance. [JAX benchmarking boundaries](https://docs.jax.dev/en/latest/benchmarking.html).

`submission_ms` and `remaining_wait_ms` are adjacent host intervals. Their sum is `completed_call_ms`; neither is independently measured kernel time, and subtracting one from the other has no kernel-time interpretation. The fenced stages deliberately wait at each boundary to attribute costs. Their barriers change overlap, so use the separately measured natural request as the end-to-end result.

The profile run warms every replayed signature before capture and completes all returned arrays inside the trace. Inspect the timeline for host gaps, target compilation, copies, and device kernels; the `model_submission` annotation marks the host call, while lower-level device events show its execution. Fetch-and-consumption can include waiting for unfinished computation. A returned capture is not proof that GPU tracing dependencies were available or that useful device events were recorded. Transfer guard in the separate diagnostic run logs implicit transfers; explicit `device_put` and `device_get` remain intentional. [JAX profiling](https://docs.jax.dev/en/latest/profiling.html), [transfer guard](https://docs.jax.dev/en/latest/transfer_guard.html).
