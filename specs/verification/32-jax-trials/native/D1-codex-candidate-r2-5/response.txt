Here is a complete single-file CPU experiment using JAX, Flax NNX, Optax, and Orbax. It trains a small causal network, evaluates held-out trajectories against persistence, and saves enough state to continue the same next training update.

The experiment uses noiseless sine waves with a shared frequency of 0.25 radians per sample, independent phases and amplitudes, and lengths from 5 to 24 samples. This is deliberately small: two preceding values can predict the next value because a sine wave obeys `s[t] = 2*cos(omega)*s[t-1] - s[t-2]`. The network learns that relation; the analytic relation is used only as a data/alignment check. Persistence, `prediction = s[t-1]`, provides the forecasting baseline. Different, unknown frequencies would require a richer context or frequency conditioning.

The observation unit is a whole trajectory. The 64 training trajectories and 32 validation trajectories use separate deterministic random streams; every window stays in its trajectory's split. Values are dimensionless float32, with amplitudes between 0.7 and 1.3. No fitted preprocessing is needed. Inputs have shape `(batch, padded_time - 2, 2)`, targets and masks have shape `(batch, padded_time - 2)`, and a trajectory of length `L` contributes exactly `L - 2` targets. Features at target time `t` contain only `s[t-2]` and `s[t-1]`. This is one-step prediction using observed context; the validation metric does not measure autoregressive rollout quality.

The loss is the sum of squared errors at eligible timesteps divided by the number of eligible timesteps. Longer trajectories consequently contribute more loss units. Padding has a separate observation mask; the target mask requires both causal inputs and the target to be observed. A positionwise network needs no attention mask or recurrent carry. Empty eligible batches are rejected before differentiation. The hand fixture has eligible losses 1, 3, and 5, so its pooled loss is 3.

All model parameters are trainable. There is no dropout, normalization state, augmentation, or recurrent state; evaluation is deterministic. Adam uses a linear learning-rate schedule from 0.02 to 0.002 over 1,000 optimizer updates and global-norm clipping at 1.0. Training samples trajectories with replacement in batches of 8. The saved sampling key determines the next batch, and a saved batch cursor records data progress. Each invocation stops after its requested number of additional updates, defaulting to 300, with validation and a checkpoint every 100 updates and at the final update. The script reports whether the held-out model beats persistence, without silently selecting a different model from validation results.

NNX modules use NNX-aware differentiation and compilation, and the optimizer receives the model explicitly in its update. These calls follow the [NNX optimizer API](https://flax.readthedocs.io/en/stable/api_reference/flax.nnx/training/optimizer.html) and [NNX transformations guide](https://flax.readthedocs.io/en/stable/guides/transforms.html). Saving pure dynamic state and restoring into a reconstructed target follows the [Flax checkpoint guide](https://flax.readthedocs.io/en/stable/guides/checkpointing.html) and [Orbax checkpoint guide](https://orbax.readthedocs.io/en/latest/guides/checkpoint/orbax_checkpoint_101.html). The sampling stream advances by splitting typed keys, as described in [JAX's random-number guide](https://docs.jax.dev/en/latest/random-numbers.html); schedule units follow [Optax's schedule API](https://optax.readthedocs.io/en/latest/api/optimizer_schedules.html).

#!/usr/bin/env python3
"""Small CPU sine forecaster with masked training and resumable state."""

import os

# Set the backend before importing JAX, even on machines with an accelerator.
os.environ["JAX_PLATFORMS"] = "cpu"

import argparse
from dataclasses import dataclass
import hashlib
from importlib.metadata import version
import json
from pathlib import Path
import platform
import re
import tempfile
import uuid

import jax
import jax.numpy as jnp
import numpy as np
import optax
import orbax.checkpoint as ocp
from flax import nnx

jax.config.update("jax_enable_x64", False)

BASE_CONFIG = {
    "format_version": 1,
    "experiment": "sine-two-lag-mlp-v1",
    "data_recipe": "independent-phase-amplitude-length-v1",
    "seed": 42,
    "train_tag": 10,
    "validation_tag": 20,
    "initialization_tag": 30,
    "sampling_tag": 40,
    "tiny_tag": 50,
    "rng_impl": "threefry2x32",
    "dtype": "float32",
    "frequency": 0.25,
    "amplitude_min": 0.7,
    "amplitude_max": 1.3,
    "min_length": 5,
    "max_length": 24,
    "train_size": 64,
    "validation_size": 32,
    "batch_size": 8,
    "hidden_width": 16,
    "learning_rate": 0.02,
    "final_learning_rate": 0.002,
    "schedule_updates": 1000,
    "clip_norm": 1.0,
    "save_every": 100,
    "tiny_updates": 150,
    "tiny_loss_ratio": 0.2,
}

CHECKPOINT_NAME = re.compile(r"step-(\d{8})-([0-9a-f]{32})")
METADATA_FIELDS = {"environment", "source_sha256", "data_sha256"}


def environment_record():
    packages = ("jax", "jaxlib", "flax", "optax", "orbax-checkpoint", "numpy")
    return {
        "packages": {name: version(name) for name in packages},
        "python": platform.python_version(),
        "machine": platform.machine(),
        "system": platform.system(),
        "backend": jax.default_backend(),
        "device_kinds": [device.device_kind for device in jax.devices()],
        "device_count": len(jax.devices()),
        "x64": bool(jax.config.jax_enable_x64),
    }


def source_digest():
    return hashlib.sha256(Path(__file__).read_bytes()).hexdigest()


def root_key(config):
    return jax.random.key(config["seed"], impl=config["rng_impl"])


def tagged_key(config, tag):
    return jax.random.fold_in(root_key(config), tag)


def sequence_digest(sequences):
    digest = hashlib.sha256()
    for name in ("values", "lengths"):
        array = np.ascontiguousarray(np.asarray(sequences[name]))
        digest.update(name.encode())
        digest.update(str(array.dtype).encode())
        digest.update(str(array.shape).encode())
        digest.update(array.tobytes())
    return digest.hexdigest()


def make_sequences(config, tag, size):
    length_key, phase_key, amplitude_key = jax.random.split(
        tagged_key(config, tag), 3
    )
    lengths = jax.random.randint(
        length_key,
        (size,),
        minval=config["min_length"],
        maxval=config["max_length"] + 1,
        dtype=jnp.int32,
    )
    phases = jax.random.uniform(
        phase_key, (size, 1), dtype=jnp.float32, maxval=2 * jnp.pi
    )
    amplitudes = jax.random.uniform(
        amplitude_key,
        (size, 1),
        dtype=jnp.float32,
        minval=config["amplitude_min"],
        maxval=config["amplitude_max"],
    )
    time = jnp.arange(config["max_length"], dtype=jnp.float32)[None, :]
    waves = amplitudes * jnp.sin(phases + config["frequency"] * time)
    observed = time < lengths[:, None]
    return {"values": jnp.where(observed, waves, 0.0), "lengths": lengths}


def make_datasets(config):
    train = make_sequences(config, config["train_tag"], config["train_size"])
    validation = make_sequences(
        config, config["validation_tag"], config["validation_size"]
    )
    # IDs refer to whole trajectories, never independently split windows.
    train_ids = {(config["train_tag"], i) for i in range(config["train_size"])}
    val_ids = {
        (config["validation_tag"], i)
        for i in range(config["validation_size"])
    }
    assert train_ids.isdisjoint(val_ids)
    return train, validation


def new_config_and_data():
    config = dict(BASE_CONFIG)
    config["environment"] = environment_record()
    config["source_sha256"] = source_digest()
    train, validation = make_datasets(config)
    config["data_sha256"] = {
        "train": sequence_digest(train),
        "validation": sequence_digest(validation),
    }
    validate_saved_config(config)
    return config, train, validation


def validate_saved_config(config):
    """Validate one authoritative reconstruction config before factories."""
    if set(config) != set(BASE_CONFIG) | METADATA_FIELDS:
        raise ValueError("checkpoint configuration schema differs from this script")
    static = {name: config[name] for name in BASE_CONFIG}
    if static != BASE_CONFIG:
        raise ValueError("checkpoint architecture/data/optimizer contract differs")
    if config["environment"] != environment_record():
        raise ValueError(
            "resume requires the saved package, Python, CPU, and precision profile"
        )
    if config["source_sha256"] != source_digest():
        raise ValueError("script changed; use the exact saved script for recovery")
    fingerprints = config["data_sha256"]
    if not isinstance(fingerprints, dict) or set(fingerprints) != {
        "train", "validation"
    }:
        raise ValueError("missing dataset fingerprints")
    if any(
        not isinstance(value, str) or re.fullmatch(r"[0-9a-f]{64}", value) is None
        for value in fingerprints.values()
    ):
        raise ValueError("invalid dataset fingerprints")


def validate_batch(batch):
    features, targets, mask = map(np.asarray, batch)
    if features.ndim != 3 or features.shape[-1] != 2:
        raise ValueError("features must have shape (batch, time, 2)")
    if targets.shape != features.shape[:2] or mask.shape != targets.shape:
        raise ValueError("target/mask shape mismatch")
    if features.dtype != np.float32 or targets.dtype != np.float32:
        raise ValueError("features and targets must be float32")
    if mask.dtype != np.bool_:
        raise ValueError("mask must be boolean")
    if not mask.any():
        raise ValueError("batch has no eligible targets")
    # Padding is finite too: masking after an undefined operation is unsafe.
    if not np.isfinite(features).all() or not np.isfinite(targets).all():
        raise ValueError("nonfinite input or target, including padding")


def make_batch(sequences):
    values, lengths = sequences["values"], sequences["lengths"]
    if values.ndim != 2 or lengths.shape != (values.shape[0],):
        raise ValueError("invalid padded sequence shapes")
    host_lengths = np.asarray(lengths)
    if lengths.dtype != jnp.int32:
        raise ValueError("lengths must be int32")
    if (host_lengths < 3).any() or (host_lengths > values.shape[1]).any():
        raise ValueError("each trajectory requires 3 <= length <= padded time")
    observation_mask = jnp.arange(values.shape[1])[None, :] < lengths[:, None]
    features = jnp.stack((values[:, :-2], values[:, 1:-1]), axis=-1)
    targets = values[:, 2:]
    loss_mask = (
        observation_mask[:, :-2]
        & observation_mask[:, 1:-1]
        & observation_mask[:, 2:]
    )
    np.testing.assert_array_equal(
        np.asarray(loss_mask.sum(axis=1)), host_lengths - 2
    )
    batch = (features, targets, loss_mask)
    validate_batch(batch)
    return batch


def masked_mean(values, mask):
    # Caller rejects zero eligible units; this is not a clamp-to-zero metric.
    return jnp.where(mask, values, 0.0).sum() / mask.sum()


def masked_mse(predictions, targets, mask):
    return masked_mean(jnp.square(predictions - targets), mask)


class LagForecaster(nnx.Module):
    def __init__(self, config, rngs):
        self.hidden = nnx.Linear(2, config["hidden_width"], rngs=rngs)
        self.output = nnx.Linear(config["hidden_width"], 1, rngs=rngs)

    def __call__(self, features):
        return self.output(jnp.tanh(self.hidden(features)))[..., 0]


def objective(model, features, targets, mask):
    return masked_mse(model(features), targets, mask)


@nnx.jit
def loss_and_gradients(model, features, targets, mask):
    loss, grads = nnx.value_and_grad(
        objective, argnums=nnx.DiffState(0, nnx.Param)
    )(model, features, targets, mask)
    finite = jnp.isfinite(loss) & jnp.isfinite(model(features)).all()
    for leaf in jax.tree.leaves(grads):
        finite = finite & jnp.isfinite(leaf).all()
    return loss, grads, finite, optax.global_norm(grads)


@nnx.jit
def apply_gradients(model, optimizer, grads):
    optimizer.update(model, grads)


def require_finite_tree(tree):
    for leaf in jax.tree.leaves(tree):
        if not np.isfinite(np.asarray(leaf)).all():
            raise FloatingPointError("nonfinite state leaf")


def update_batch(model, optimizer, batch):
    validate_batch(batch)
    model.train()
    loss, grads, finite, grad_norm = loss_and_gradients(model, *batch)
    if not bool(finite) or not np.isfinite(float(grad_norm)):
        raise FloatingPointError("nonfinite predictions, loss, or gradient")
    # The host gate prevents applying nonfinite gradients to optimizer state.
    apply_gradients(model, optimizer, grads)
    require_finite_tree(nnx.state(model).to_pure_dict())
    require_finite_tree(nnx.state(optimizer).to_pure_dict())
    return float(loss), float(grad_norm)


def make_training(config, initialization_key):
    model = LagForecaster(config, nnx.Rngs(params=initialization_key))
    schedule = optax.linear_schedule(
        init_value=config["learning_rate"],
        end_value=config["final_learning_rate"],
        transition_steps=config["schedule_updates"],
    )
    transformation = optax.chain(
        optax.clip_by_global_norm(config["clip_norm"]), optax.adam(schedule)
    )
    optimizer = nnx.Optimizer(model, transformation, wrt=nnx.Param)
    model.train()
    return model, optimizer, schedule


@dataclass
class Run:
    config: dict
    training: dict
    validation: dict
    model: LagForecaster
    optimizer: nnx.Optimizer
    schedule: object
    key: jax.Array
    step: int = 0
    cursor: int = 0


def make_run(config, train, validation):
    model, optimizer, schedule = make_training(
        config, tagged_key(config, config["initialization_tag"])
    )
    return Run(
        config, train, validation, model, optimizer, schedule,
        tagged_key(config, config["sampling_tag"])
    )


def peek_next_batch(run):
    next_key, sample_key = jax.random.split(run.key)
    indices = jax.random.randint(
        sample_key,
        (run.config["batch_size"],),
        minval=0,
        maxval=run.training["values"].shape[0],
        dtype=jnp.int32,
    )
    sequences = {name: value[indices] for name, value in run.training.items()}
    return next_key, indices, make_batch(sequences)


def advance(run):
    if run.step != int(run.optimizer.step[...]) or run.cursor != run.step:
        raise ValueError("driver, optimizer, and sampling cursor disagree")
    next_key, _, batch = peek_next_batch(run)
    loss, grad_norm = update_batch(run.model, run.optimizer, batch)
    # Model/optimizer mutation and these assignments form one driver transition.
    run.key = next_key
    run.step += 1
    run.cursor += 1
    if int(run.optimizer.step[...]) != run.step:
        raise ValueError("optimizer failed to advance exactly once")
    return loss, grad_norm


def evaluate(model, sequences):
    batch = make_batch(sequences)
    features, targets, mask = batch
    model.eval()
    predictions = model(features)
    if not np.isfinite(np.asarray(predictions)).all():
        raise FloatingPointError("nonfinite evaluation prediction")
    loss = float(masked_mse(predictions, targets, mask))
    persistence = float(masked_mse(features[..., 1], targets, mask))
    if not np.isfinite([loss, persistence]).all():
        raise FloatingPointError("nonfinite evaluation metric")
    return {"mse": loss, "persistence_mse": persistence, "units": int(mask.sum())}


def snapshot(run):
    return {
        "model": nnx.state(run.model).to_pure_dict(),
        "optimizer": nnx.state(run.optimizer).to_pure_dict(),
        "key_data": jax.random.key_data(run.key),
        "external_step": jnp.array(run.step, dtype=jnp.int32),
        "cursor": jnp.array(run.cursor, dtype=jnp.int32),
    }


def restore_nnx(obj, pure_state):
    state = nnx.state(obj)
    state.replace_by_pure_dict(pure_state)
    nnx.update(obj, state)


def assert_same_tree(left, right):
    assert jax.tree.structure(left) == jax.tree.structure(right)
    for a, b in zip(jax.tree.leaves(left), jax.tree.leaves(right)):
        a, b = np.asarray(a), np.asarray(b)
        assert a.shape == b.shape and a.dtype == b.dtype
        if np.issubdtype(a.dtype, np.inexact):
            np.testing.assert_allclose(a, b, rtol=1e-6, atol=1e-6)
        else:
            np.testing.assert_array_equal(a, b)


def checkpoint_step(path):
    match = CHECKPOINT_NAME.fullmatch(path.name)
    if match is None:
        raise ValueError(f"unrecognized checkpoint directory: {path}")
    return int(match.group(1))


def completed_checkpoints(root):
    candidates = [
        path for path in root.glob("step-*")
        if path.is_dir()
        and CHECKPOINT_NAME.fullmatch(path.name) is not None
        and (path / "COMPLETE").is_file()
        and (path / "config.json").is_file()
        and (path / "state").is_dir()
    ]
    return sorted(candidates, key=lambda path: (checkpoint_step(path), path.name))


def latest_checkpoint(root):
    candidates = completed_checkpoints(root)
    if not candidates:
        raise FileNotFoundError(f"no completed checkpoints in {root}")
    return candidates[-1]


def save_progress(checkpointer, root, run):
    if run.step > 99_999_999:
        raise ValueError("checkpoint naming limit exceeded")
    run.model.train()
    # A fresh suffix also avoids collisions with an interrupted partial save.
    progress = root / f"step-{run.step:08d}-{uuid.uuid4().hex}"
    progress.mkdir(parents=True)
    (progress / "config.json").write_text(
        json.dumps(run.config, sort_keys=True, indent=2), encoding="utf-8"
    )
    checkpointer.save(progress / "state", snapshot(run))
    checkpointer.wait_until_finished()
    # Restore selection sees this only after Orbax finishes successfully.
    (progress / "COMPLETE").write_text(str(run.step), encoding="utf-8")
    return progress


def restore_progress(checkpointer, progress):
    config = json.loads((progress / "config.json").read_text(encoding="utf-8"))
    validate_saved_config(config)
    # All resumed factories consume the loaded and validated configuration.
    train, validation = make_datasets(config)
    regenerated = {
        "train": sequence_digest(train), "validation": sequence_digest(validation)
    }
    if regenerated != config["data_sha256"]:
        raise ValueError("regenerated datasets differ from saved datasets")
    run = make_run(config, train, validation)
    loaded = checkpointer.restore(progress / "state", target=snapshot(run))
    restore_nnx(run.model, loaded["model"])
    restore_nnx(run.optimizer, loaded["optimizer"])
    run.key = jax.random.wrap_key_data(
        loaded["key_data"], impl=config["rng_impl"]
    )
    run.step = int(loaded["external_step"])
    run.cursor = int(loaded["cursor"])
    if run.step != checkpoint_step(progress):
        raise ValueError("checkpoint directory and external step disagree")
    if run.step != int(run.optimizer.step[...]) or run.cursor != run.step:
        raise ValueError("saved progress counters disagree")
    require_finite_tree(snapshot(run))
    run.model.train()
    return run


def tiny_sequences(config):
    lengths = jnp.array([5, 7, 9, 12], dtype=jnp.int32)
    phases = jax.random.uniform(
        tagged_key(config, config["tiny_tag"]), (4, 1),
        dtype=jnp.float32, maxval=2 * jnp.pi
    )
    time = jnp.arange(12, dtype=jnp.float32)[None, :]
    waves = jnp.sin(phases + config["frequency"] * time)
    return {
        "values": jnp.where(time < lengths[:, None], waves, 0.0),
        "lengths": lengths,
    }


def check_objective_and_learning(config):
    hand_losses = jnp.array(
        [[1.0, 100.0, 100.0], [3.0, 5.0, 100.0]], dtype=jnp.float32
    )
    hand_mask = jnp.array([[True, False, False], [True, True, False]])
    np.testing.assert_allclose(masked_mean(hand_losses, hand_mask), 3.0)
    np.testing.assert_allclose(
        masked_mean(jnp.where(hand_mask, hand_losses, -999.0), hand_mask), 3.0
    )

    # Plain JAX differentiates this pure-array loss, not an NNX module.
    predictions = jnp.sqrt(hand_losses)
    reference_gradient = jnp.where(hand_mask, 2 * predictions / 3, 0.0)
    actual_gradient = jax.grad(
        lambda p: masked_mse(p, jnp.zeros_like(p), hand_mask)
    )(predictions)
    np.testing.assert_allclose(actual_gradient, reference_gradient, atol=1e-6)

    empty = (
        jnp.zeros((1, 2, 2), dtype=jnp.float32),
        jnp.zeros((1, 2), dtype=jnp.float32),
        jnp.zeros((1, 2), dtype=jnp.bool_),
    )
    try:
        validate_batch(empty)
    except ValueError as error:
        assert "no eligible" in str(error)
    else:
        raise AssertionError("empty eligible batch was accepted")

    sequences = tiny_sequences(config)
    batch = make_batch(sequences)
    features, targets, mask = batch
    assert features.shape == (4, 10, 2)
    assert targets.shape == mask.shape == (4, 10)
    assert int(mask.sum()) == 25
    analytic = (
        2 * jnp.cos(config["frequency"]) * features[..., 1] - features[..., 0]
    )
    np.testing.assert_allclose(
        np.asarray(analytic)[np.asarray(mask)],
        np.asarray(targets)[np.asarray(mask)], rtol=1e-5, atol=1e-6
    )

    model, optimizer, _ = make_training(
        config, tagged_key(config, config["tiny_tag"] + 1)
    )
    model.eval()
    initial = float(objective(model, *batch))
    _, grads, finite, _ = loss_and_gradients(model, *batch)
    assert bool(finite), "initial loss/prediction/gradient is nonfinite"
    require_finite_tree(grads)
    valid = np.asarray(mask)
    original_predictions = model(features)

    # Change raw padding, then reconstruct every lag and target from it.
    observation_mask = (
        jnp.arange(sequences["values"].shape[1])[None, :]
        < sequences["lengths"][:, None]
    )
    changed = {
        **sequences,
        "values": jnp.where(observation_mask, sequences["values"], 99.0),
    }
    changed_batch = make_batch(changed)
    np.testing.assert_allclose(
        np.asarray(original_predictions)[valid],
        np.asarray(model(changed_batch[0]))[valid], atol=1e-6
    )
    np.testing.assert_allclose(
        objective(model, *batch), objective(model, *changed_batch), atol=1e-6
    )
    changed_targets = jnp.where(mask, targets, 999.0)
    np.testing.assert_allclose(
        objective(model, *batch),
        objective(model, features, changed_targets, mask), atol=1e-6
    )

    extended = {
        **sequences,
        "values": jnp.pad(sequences["values"], ((0, 0), (0, 4))),
    }
    np.testing.assert_allclose(
        objective(model, *batch), objective(model, *make_batch(extended)), atol=1e-6
    )
    future_changed = {
        **sequences, "values": sequences["values"].at[:, 4:].set(50.0)
    }
    # Outputs 0 and 1 predict raw times 2 and 3, before the altered suffix.
    np.testing.assert_allclose(
        model(make_batch(future_changed)[0])[:, :2],
        original_predictions[:, :2], atol=1e-6
    )

    for _ in range(config["tiny_updates"]):
        update_batch(model, optimizer, batch)
    model.eval()
    final = float(objective(model, *batch))
    assert final < config["tiny_loss_ratio"] * initial, (initial, final)
    assert int(optimizer.step[...]) == config["tiny_updates"]
    np.testing.assert_array_equal(model(features), model(features))
    print(
        f"correctness: loss/count/masks/causality/finite gradients; "
        f"fixed tiny loss {initial:.6g} -> {final:.6g} "
        f"in {config['tiny_updates']} updates"
    )


def check_recovery(config):
    """Isolated run: its updates never advance the user's training run."""
    train, validation = make_datasets(config)
    original = make_run(config, train, validation)
    with tempfile.TemporaryDirectory(prefix="sine-recovery-") as directory:
        root = Path(directory).resolve()
        with ocp.StandardCheckpointer() as checkpointer:
            for milestone in (3, 5):
                while original.step < milestone:
                    advance(original)
                save_progress(checkpointer, root, original)
            assert [checkpoint_step(p) for p in completed_checkpoints(root)] == [3, 5]
            # An interrupted later directory must not be chosen for restoration.
            partial = root / f"step-00000006-{uuid.uuid4().hex}"
            partial.mkdir()
            latest = latest_checkpoint(root)
            assert checkpoint_step(latest) == 5
            restored = restore_progress(checkpointer, latest)
            assert restored.config == config
            assert_same_tree(snapshot(original), snapshot(restored))
            old_key_data = np.asarray(jax.random.key_data(original.key)).copy()

            original_next_key, original_ids, original_batch = peek_next_batch(original)
            restored_next_key, restored_ids, restored_batch = peek_next_batch(restored)
            np.testing.assert_array_equal(original_ids, restored_ids)
            assert_same_tree(original_batch, restored_batch)
            np.testing.assert_array_equal(
                jax.random.key_data(original_next_key),
                jax.random.key_data(restored_next_key)
            )
            np.testing.assert_allclose(
                original.schedule(original.step), restored.schedule(restored.step)
            )

            uninterrupted_loss, uninterrupted_norm = advance(original)
            resumed_loss, resumed_norm = advance(restored)
            np.testing.assert_allclose(
                [uninterrupted_loss, uninterrupted_norm],
                [resumed_loss, resumed_norm], rtol=1e-6, atol=1e-6
            )
            # Includes parameters, ALL Adam moments/counts, external step,
            # optimizer step, sampling RNG, and next data cursor.
            assert_same_tree(snapshot(original), snapshot(restored))
            assert original.step == restored.step == 6
            assert original.cursor == restored.cursor == 6
            np.testing.assert_allclose(
                original.schedule(original.step), restored.schedule(restored.step)
            )
            assert not np.array_equal(
                old_key_data, np.asarray(jax.random.key_data(original.key))
            )
    print("recovery: two saves, restore latest, batch and next full update agree")


def predict_next(model, observed_values):
    """Forecast one sample after a finite, unpadded observed prefix."""
    values = np.asarray(observed_values, dtype=np.float32)
    if values.ndim != 1 or len(values) < 2 or not np.isfinite(values).all():
        raise ValueError("provide at least two finite observed samples")
    model.eval()
    features = jnp.asarray(values[-2:])[None, None, :]
    return float(model(features)[0, 0])


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--checkpoint-dir", type=Path, default=Path("sine-checkpoints"))
    parser.add_argument("--resume", action="store_true")
    parser.add_argument(
        "--updates", type=int, default=300,
        help="number of additional optimizer updates in this invocation"
    )
    parser.add_argument("--check-only", action="store_true")
    args = parser.parse_args()
    if args.updates < 1:
        parser.error("--updates must be positive")
    root = args.checkpoint_dir.expanduser().resolve()
    if jax.default_backend() != "cpu":
        raise RuntimeError("this experiment requires the CPU backend")

    with ocp.StandardCheckpointer() as checkpointer:
        if args.resume:
            progress = latest_checkpoint(root)
            # Saved configuration is validated before any resumed factory.
            run = restore_progress(checkpointer, progress)
            print(f"restored {progress}; step={run.step}, cursor={run.cursor}")
        else:
            if any(root.glob("step-*")):
                raise FileExistsError(
                    "checkpoint directory has progress; use --resume or a new directory"
                )
            config, train, validation = new_config_and_data()
            run = make_run(config, train, validation)

        print("environment:", json.dumps(run.config["environment"], sort_keys=True))
        check_objective_and_learning(run.config)
        check_recovery(run.config)
        if args.check_only:
            return

        initial_train = evaluate(run.model, run.training)
        initial_val = evaluate(run.model, run.validation)
        print(f"start step={run.step}; train={initial_train}; validation={initial_val}")
        stop_step = run.step + args.updates
        if stop_step > 99_999_999:
            raise ValueError("requested updates exceed checkpoint naming limit")
        root.mkdir(parents=True, exist_ok=True)
        clipped = 0
        last_save_step = None
        for _ in range(args.updates):
            loss, grad_norm = advance(run)
            clipped += int(grad_norm > run.config["clip_norm"])
            if run.step % run.config["save_every"] == 0 or run.step == stop_step:
                train_metrics = evaluate(run.model, run.training)
                val_metrics = evaluate(run.model, run.validation)
                progress = save_progress(checkpointer, root, run)
                last_save_step = run.step
                print(
                    f"step={run.step}; batch_mse={loss:.6g}; "
                    f"next_lr={float(run.schedule(run.step)):.6g}; "
                    f"train={train_metrics}; validation={val_metrics}; saved={progress}"
                )
        assert last_save_step == run.step == stop_step
        final_train = evaluate(run.model, run.training)
        final_val = evaluate(run.model, run.validation)
        print(
            f"same fixed training dataset: {initial_train['mse']:.6g} "
            f"-> {final_train['mse']:.6g}; "
            f"clipped_update_fraction={clipped / args.updates:.3f}"
        )
        print(
            f"held-out target met (MSE below persistence): "
            f"{final_val['mse'] < final_val['persistence_mse']}"
        )
        # Show inference at the last observed member, excluding its right-padding.
        length = int(run.validation["lengths"][0])
        prefix = np.asarray(run.validation["values"][0, :length])
        print(f"next sample after validation prefix: {predict_next(run.model, prefix):.6g}")
        print(f"resume with --resume --checkpoint-dir {root}")


if __name__ == "__main__":
    main()

The recovery boundary is the last completed save, including the final successful update of a normal invocation. An interruption between saves can lose up to 99 unsaved updates at the default interval. Each save gets its own progress directory, and incomplete directories are ignored when selecting the latest checkpoint. This is a single-process, single-writer checkpoint policy; no directory is overwritten. Keep `sine_forecast.py` unchanged for strict recovery. The checkpoint validates the exact source digest, static configuration, package versions, Python/CPU environment, and regenerated dataset fingerprints before resumed updates. A changed configuration or environment requires an explicit migration rather than silently continuing a different experiment.

The saved dynamic state contains model parameters, the complete optimizer state including Adam moments and internal schedule counters, the optimizer's own step, an independent driver step, the sampling key buffer and its implementation, and the next batch cursor. Static architecture, optimizer, schedule, data generation, split, and preprocessing contracts are stored in `config.json`. The isolated recovery fixture makes saves at steps 3 and 5, restores step 5 even with a later incomplete directory, and compares the next selected batch, loss, gradient norm, full post-update model and optimizer trees, step counters, schedule output, key progression, and data cursor against uninterrupted execution. Floating-point comparisons use a tolerance of `1e-6`; this provides a same-environment numerical-parity check, not a bitwise or cross-version guarantee.

The implementation also checks target alignment against the sine identity, the exact eligible count of 25 in the tiny fixture, the hand-computed masked loss, its analytic prediction gradient, rejection of empty batches, finite predictions/loss/all differentiated gradient leaves, invariance to changed padding and added padding, and causality under changed future inputs. Its independent 150-update fixed fixture must reduce deterministic evaluation loss by at least 80%. That check uses a separate model and optimizer, so it cannot leave the main run with stale RNG or data progress. Train and validation metrics sum over all eligible timesteps, and validation uses only its held-out trajectories.

The actual check performed here was static syntax validation: Python's `ast.parse` accepted the 720-line program. No application/model code was executed. Training, numerical, learning, validation, and recovery results therefore remain unmeasured. The script will print those results when run and stop if a correctness or recovery assertion fails. The main held-out persistence comparison is reported separately from tiny-fixture learnability. This establishes a small one-step, fixed-frequency experiment; it does not establish quality for unknown frequencies, noisy sequences, multi-step rollouts, accelerators, distributed loading, or recovery after dependency changes.
