# Proposal: one sentence in api-error-messages

Old sentence: "Say what went wrong."

New sentence: "Say what went wrong and the next step the caller can take."

## Why

Developers who read our errors ask the support team what to do next. The old sentence asks only for the
cause, so agents write messages that name the problem and stop there. The new sentence asks for the next step
too, such as the value to send or the endpoint to call first.
