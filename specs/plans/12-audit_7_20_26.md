### Task 1: C1 — repair the crashing prior-predictive recipe

The skill's *mandatory* prior-predictive step raises on the exact stack `SKILL.md:59` declares. Root cause: `az.from_numpyro` needs an MCMC trace to distinguish the observed site from latent sites. Pre-fit, `Predictive` returns a bare dict with no trace, so the converter raises `ValueError: sample_dims must be provided if posterior is None`; silencing that with `sample_dims=['sample']` lumps every site including `y_obs` into a single `prior` group, so `plot_ppc_dist(..., group='prior_predictive')` then dies with `KeyError`. Fix: assemble groups explicitly with `az.from_dict`, adding a leading chain axis so ArviZ 1.x's default `sample_dims=('chain','draw')` applies.

from numpyro.infer import Predictive

def model(x, y=None):
    alpha = numpyro.sample('alpha', dist.Normal(0, 1))
    beta = numpyro.sample('beta', dist.Normal(0, 1))

The contradiction is purely lexical — a "frown" is ∩, not ∪, and each file paired the word with the wrong glyph. Ground truth, `y ~ N(0,1)`: too-narrow `N(0,0.5)` gives a ∪ histogram and coverage-ΔECDF mean −0.212; too-broad `N(0,2)` gives a ∩ histogram and +0.215. ### Task 3: C3 — `HalfCauchy` is proper, not improper

`SKILL.md` labels `HalfCauchy` improper. It is also not flat. **The practical advice is correct and must survive:** `diagnostics.md:117` and `reporting.md:213` give the same recommendation without the false word, and `priors.md:164` correctly calls `dist.HalfCauchy` the textbook horseshoe choice for `tau`/`lam`. **Interfaces:** none.

- [ ] **Step 1: Apply the edit**

Replace exactly this text:

```
- **Flat priors on scale parameters** (`HalfCauchy`, improper) cause funnels in hierarchical models. Use `Gamma(2, ...)`, `HalfNormal`, or `Exponential` — these avoid the near-zero region that creates sampling problems. If there's no group-level variation to detect, you don't need the hierarchy.
```

with exactly this text:

```
- **Heavy-tailed or near-flat priors on scale parameters** cause funnels in hierarchical models. `HalfCauchy` is *proper* — it is the classic weakly-informative choice (Gelman 2006), not an improper flat prior — but its heavy tail puts substantial mass near 0, which is what creates the funnel. ```
